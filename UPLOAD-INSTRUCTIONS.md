# Upload checklist

1. Extract `Daiju-Hoshino-Portfolio-GitHub-Pages.zip` on your computer.
2. Open your `dhoshino44/Portfolio` repository on GitHub.
3. Select **Add file** and then **Upload files**.
4. Drag every extracted item into the upload area:
   - `.nojekyll`
   - `index.html`
   - `styles.css`
   - `README.md`
   - `UPLOAD-INSTRUCTIONS.md`
   - the complete `assets` folder
5. If GitHub does not display `.nojekyll` in your file browser, that is normal; hidden files may not be obvious on every computer.
6. Enter the commit message `Publish portfolio website`.
7. Choose **Commit directly to the main branch** and select **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Choose `main` and `/ (root)`, then select **Save**.

Once GitHub finishes publishing, open:

`https://dhoshino44.github.io/Portfolio/`
