# Daiju Hoshino Portfolio

This repository contains the static personal website of Daiju Hoshino, an educator, biologist, department chair, faculty developer, and builder working at the intersection of learning, data, and responsible AI.

## View locally

Open `index.html` in a web browser. No installation or build process is required.

## Publish with GitHub Pages

1. Upload every extracted file to the root of the repository's `main` branch.
2. In the GitHub repository, open **Settings**.
3. Select **Pages** under **Code and automation**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Click **Save**.

GitHub will provide the published address after deployment. For a repository named `Portfolio`, the expected address is:

`https://dhoshino44.github.io/Portfolio/`

## Files

- `index.html` - website content and metadata
- `styles.css` - responsive Editorial Humanist visual design
- `hero-editorial-biology.webp` - optimized hero artwork
- `favicon.svg` - browser icon
- `.nojekyll` - ensures GitHub Pages serves the static files directly

## Updating the site

Edit `index.html` for wording, links, and sections. Edit `styles.css` for colors, typography, spacing, and responsive layout. Relative asset paths are used so the site works correctly from a GitHub project repository.
